================================================================================
                              TOOL DEFINITIONS
================================================================================

Tool 1: get_weather
├─ Purpose: Get current weather for a city
├─ Parameters:
│  ├─ location (string, required): "Paris", "London", "Tokyo", "New York"
│  └─ unit (enum, optional): "C" or "F" (default: "C")
└─ Returns: "22°C, Partly Cloudy, Humidity: 65%"

Tool 2: calculate_distance
├─ Purpose: Get distance between two cities
├─ Parameters:
│  ├─ city1 (string, required): First city
│  └─ city2 (string, required): Second city
└─ Returns: "9,730 km"

Tool 3: add_numbers
├─ Purpose: Add two numbers
├─ Parameters:
│  ├─ a (number, required): First number
│  └─ b (number, required): Second number
└─ Returns: "23"

Tool 4: multiply_numbers
├─ Purpose: Multiply two numbers
├─ Parameters:
│  ├─ a (number, required): First number
│  └─ b (number, required): Second number
└─ Returns: "69"
